# Lead Finder Website

A simple static website that helps users search public web sources for businesses that may need a website.

## Run locally

```bash
cd /Users/waleedxyarmmok/lead-finder-website
ruby -run -e httpd . -p 8000 -b 0.0.0.0
```

Then open http://127.0.0.1:8000/.

## Publish publicly

You can publish this site on GitHub Pages, Netlify, or Vercel by uploading the files in this folder.
